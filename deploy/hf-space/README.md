# Indonesian Food Scanner

Upload a photo of a meal. A YOLOv8n model trained on 29 Indonesian and common foods finds each dish and estimates its nutrition per 100 g.

- Web app: the Space's main page
- Gradio demo and API: `/gradio`

Source code, training results and details: https://github.com/Ahmad-FikriA/ai_food_detection
